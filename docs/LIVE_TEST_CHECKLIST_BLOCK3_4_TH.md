# เช็กลิสต์ทดสอบระบบจริง Block 3–4

ทำบนโดเมน/อุปกรณ์จริงโดยเจ้าของร้าน รายการนี้มี 24 ข้อพอดี

1. [ ] ล็อกอินด้วย owner แล้วเข้าหน้าหลักได้
2. [ ] ล็อกอินด้วย admin แล้วไม่เห็นหน้าระบบ + ความลับ
3. [ ] ล็อกอินด้วย viewer แล้วส่งข้อความไม่ได้
4. [ ] เปิดอินบ็อกซ์บนมือถือแนวตั้งและไม่มีแถบเลื่อนแนวนอน
5. [ ] สลับไปแอปอื่น 1 นาทีแล้วกลับมา อินบ็อกซ์อัปเดตต่อ
6. [ ] สลับห้องเร็ว ๆ แล้วไม่มีข้อความห้องก่อนปน
7. [ ] เลื่อนอ่านข้อความเก่าแล้ว polling ไม่ดึงจอลงล่าง
8. [ ] ค้นด้วยชื่อลูกค้า
9. [ ] ค้นด้วยเบอร์โทร
10. [ ] ค้นด้วยเลขออเดอร์
11. [ ] ค้นด้วยเลขพัสดุ
12. [ ] ส่งข้อความธรรมดาแล้วสถานะเป็นส่งแล้ว
13. [ ] ทำเคสถูก policy บล็อกแล้วเห็นเหตุผล
14. [ ] ทำเคส outcome unknown แล้วไม่มีปุ่มส่งซ้ำง่าย ๆ
15. [ ] แตะข้อความที่มีที่อยู่แล้วสร้างออเดอร์ ฟอร์มถูก preload
16. [ ] แตะรูปถาวรแล้วแนบกับออเดอร์
17. [ ] แตะรูปถาวรแล้วตั้งเป็นสลิป
18. [ ] อัปโหลดและส่งรูป แล้วเปิดสำเนาขาออกย้อนหลังได้
19. [ ] เปิดหน้าแจ้งเตือนแล้วเห็นเวลา flush/heartbeat ล่าสุด
20. [ ] หยุด worker เกิน 30 นาทีแล้วเห็นคำเตือน
21. [ ] บันทึกค่าทั่วไปจากหน้าเว็บแล้วมีผลโดยไม่รีสตาร์ต
22. [ ] บันทึกค่าลับแล้ว GET เห็นเฉพาะสี่ตัวท้าย
23. [ ] เว้นช่องค่าลับว่างแล้วค่าเดิมไม่เปลี่ยน
24. [ ] ลบค่าตั้งด้วยการพิมพ์ชื่อยืนยัน และทำ backup/restore ตามคู่มือ
