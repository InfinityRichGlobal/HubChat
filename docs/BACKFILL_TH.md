# ดึงแชทเก่าเข้าระบบ (Backfill)

> เขียนให้เจ้าของร้านอ่านเอง ไม่ต้องรู้เรื่องโค้ด

---

## 1. ทำไมเปิดระบบมาแล้วเห็นแต่แชททดสอบ

ไม่ใช่ระบบพัง — เป็นวิธีทำงานของ Meta เอง

Meta ส่งข้อความมาให้เราแบบ "ส่งเมื่อเกิดเหตุการณ์" (webhook)
แปลว่า **ส่งให้เฉพาะข้อความที่เกิดขึ้นหลังจากเราเชื่อมเพจเท่านั้น**

แชทที่มีอยู่ก่อนหน้านั้น Meta จะไม่ส่งย้อนหลังให้เลย ต่อให้รอเป็นเดือน
เราต้อง "ไปดึงเอง" — นั่นคือสิ่งที่ปุ่มในหน้านี้ทำ

---

## 2. วิธีดึง

1. เข้า **ตั้งค่า → จัดการเพจ**
2. ที่การ์ดของเพจที่ต้องการ กด **"ดึงแชทเก่าเข้าระบบ"**
3. ระบบจะทยอยดึงเป็นชุด ๆ พร้อมนับให้ดูว่าได้กี่ห้อง กี่ข้อความ
4. กด **"หยุด"** ได้ตลอดเวลา ของที่ดึงมาแล้วไม่หาย
5. ถ้ายังไม่หมด ปุ่มจะเปลี่ยนเป็น **"ดึงต่อ (ยังเหลืออีก)"** — กดต่อได้เลย

**กดซ้ำได้ไม่จำกัด** ข้อความที่มีอยู่แล้วจะไม่ถูกบันทึกซ้ำ
(ระบบเทียบด้วยรหัสข้อความของ Meta เอง)

---

## 3. ทำไมไม่ดึงรวดเดียวจนหมด

Meta จำกัดจำนวนครั้งที่เรียกได้ต่อชั่วโมงต่อเพจ

ถ้ายิงรัวจนชนเพดาน Meta จะตัดทั้งเพจชั่วคราว
แปลว่า **ข้อความจริงที่ลูกค้าทักเข้ามาตอนนั้นจะเข้าไม่ได้ด้วย** — เสียหายกว่าที่ได้

ระบบจึงตั้งเพดานไว้ที่ประมาณ 5,000 ห้องต่อการกดหนึ่งครั้ง
ถ้าเพจใหญ่กว่านั้น กดซ้ำอีกครั้งได้เลย

---

## 4. ถ้าขึ้นข้อความเตือน

| ข้อความที่เห็น | แปลว่า | ทำยังไง |
|---|---|---|
| token ยังไม่มีสิทธิ์อ่านประวัติแชท | token ขาดสิทธิ์ `pages_messaging` | สร้าง token ใหม่ให้ครบสิทธิ์ ดู `docs/META_SETUP_TH.md` |
| token ของเพจหมดอายุหรือถูกเพิกถอน | token ตายแล้ว | สร้างใหม่แล้วกด "เปลี่ยน token" |
| เรียก Meta ถี่เกินโควตาชั่วโมงนี้ | ชนเพดานของ Meta | รอ 15–30 นาที แล้วกดใหม่ ของเดิมไม่หาย |
| Meta ไม่ได้ส่งห้องแชทกลับมาเลย | มักเป็นเรื่องสิทธิ์ | เช็คว่าเพจอนุญาตให้แอปเข้าถึงกล่องข้อความแล้ว |

---

## 5. ข้อจำกัดที่ต้องรู้ล่วงหน้า

- **ไม่มีป้าย "จากแอด"** — Meta ไม่ให้ข้อมูลที่มาของแชทย้อนหลัง (ดู D-59)
- **ไฟล์แนบของแชทเก่ายังเปิดไม่ได้ตลอดไป** — ลิงก์รูปของ Meta เป็นลิงก์ชั่วคราว
  ระบบยังไม่ได้เก็บสำเนาของแชทเก่า (ดู D-60) รูปของข้อความ **ใหม่** เก็บให้อยู่แล้ว
- **สถานะอ่านแล้ว/ยังไม่ตอบ** เอาตามที่ Meta บอก
  ห้องที่ตอบไปแล้วใน Business Suite จะไม่เด้งเป็น "ยังไม่ตอบ"

---

## 6. หลังดึงเสร็จ

- อินบ็อกซ์จะโชว์แชทล่าสุด 50 ห้อง — เลื่อนลงสุดแล้วกด **"โหลดแชทเพิ่ม"** เพื่อดูของเก่ากว่า
- ในห้องแชท กด **"ดูข้อความเก่ากว่านี้"** ที่ด้านบนเพื่อไล่อ่านย้อนหลัง
